# 宋式衣橱 v1

自己选场合、衫、褙子、裙、头面和颜色。不是人格测验，也不是随机抽一套当答案。冬日可以另加一层棉披；棉披有立领、横向绗线和更短的袖，不是把原有衣服改个颜色。

## 边界

- 形制取宋人常服的印象：交领或直领的衫、开襟褙子、高腰裙、簪与包髻。不是某件出土文物的复原，也不使用戏文或现成 IP 形象。
- 人物是为换装新画的。没有改「宋朝配色」和「测测你是宋朝哪种女子」。
- 不上传真人照片，没有登录、服务端、定位、相机或外部 AI。

## 颜色

页面底色 `#F7F2EA`。字色是暖墨 `#3A3732`，注释 `#8A847A`。饱和色只出现在衣料和头面上。

## 动作

衣物或颜色变化时，整个人有一段约 220ms 的透明度回稳，填色约 200ms。`prefers-reduced-motion: reduce` 时这两段都关掉。平台保存、发笔记、评论、分享只在按钮点击之后调用。

## 容器

实现对照 2026-11-24 在线文档（ETag `487330165`，与交接快照相同）。评论附图只接受 `writeTempFile` 返回的本地句柄，不用 data URI 或网络地址顶替。浏览器里没有 `window.xhs.miniTool` 时，按钮会说明这是预览，不会显示成已经保存。

不调用关注、定位、陀螺仪、内测 AI、云存储、成绩榜、赞赏。没有 Worker、WASM、离屏画布或游戏引擎，`mini_tool.json` 为 `is_high_consumption_scene: false`。
