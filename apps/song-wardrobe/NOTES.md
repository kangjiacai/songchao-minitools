# 宋式衣橱 v1

固定一幅已经认可的线描淡彩（`art/source/song-wardrobe-character-trial-02-illustration.jpg` / `pkg/images/figure.png`）。抽一句或择一句宋词，得到四色，另配「素白」「墨黑」基础色，可为**褙子、内衫、里衣、裙、腰带、鞋履**六处分别设色。不换款式，不换人，不在工具里生图。

## 交互与视觉设计（方向 A · 精修版）

- **无缝暖宣纸底与居中构图**：整页、抽屉、结果页与 1080×1680 竖图海报统一 `#F5E5CE`，页面对称居中（不再因 `gestureArea` 把整体推偏右）；`platform.js` 缓存 `getWindowInfo` 矩形（含 `capsule` / `back` / `me` / `share` 最大底边 `+ 12px`），`resize` 时不再覆盖 `--content-top`，彻底避开宿主顶部按钮。
- **六部位与双基础色**：在原四部位基础上拆分最内层白领为「里衣」并开放「鞋履」独立设色；色盘右侧以细游丝线隔出「素白（`#F6F4EE`）」「墨黑（`#262422`）」两枚基础色珠。
- **统一交互与清晰可点性**：
  - 顶部「词笺 / 换词」、底部「套色 / 撤回 / 原画 / 重置」、「还原」、结果页「‹ 返回 / 发成笔记 / 晒到评论区 / 分享画册」统一使用暖宣纸轻底 + 细墨描边胶囊；
  - 同一首词内切部位/选色仅原地更新选中外环（不再重建色珠 DOM，消除其余色珠跳动）；
  - 「套色」按 4 组预设方案轮换并提示 `1/4`~`4/4`；「原画」支持点按切换对比原画与当前配色；
  - 部位切换条配顺滑滑动墨针（`.part-indicator`），换色仅对变更部位像素做 `180ms` 柔缓晕染过渡（`requestAnimationFrame` 三次缓出）；
  - Toast 改为居中浮于画卷下方的宣纸微签，不挡顶部返回或画作。
- **三态同页无缝过渡（`.is-intro` ↔ 设色 ↔ `.is-export`）与纯净竖图**：
  - 人物画布在三个状态间始终居于画心、`0px` 位移不跳动；
  - **策略 C「心境起衣」前置态**：首次打开或跨天后首次打开展示 6 枚宋式心境（清欢/烟雨/微醺/思念/孤勇/归隐）与「今日随机起衣」；评论区快照回跳时自动跳过前置页直接还原同款并提示接龙；同日内再次打开则直入首页（右上「✦ 心境」可随时重选）；
  - **成衣雅名与社区接龙文案**：按主色调与意象动态生成 4 字成衣雅名（单人 `1080×1680` 纯净竖图仍不印字，雅名仅用于浮签、衣箱、双联画卷与分享文案），评论区/发笔记自带「宋朝姑娘」社区感交互句式；
  - **落位 B 顶栏与单手底坞设计**：首页顶栏三大核心入口平权（`✦ 心境` / `≡ 词笺` / `◇ 衣箱`），`↻ 换词` 轻量移至竖排题跋正下方（前置态与定稿态自动淡隐）；点击 `↻ 换词` 或在 `≡ 词笺` 选词即同步套用该词四色（可通过 `撤回` 还原）；首页底坞在「存为画册」左侧提供「存衣箱」（存入后同步为 `✓ 已存`）；点击「存为画册」后顶栏还原静雅落款 `宋式衣橱 · <四字雅名>`，`+ 存衣箱` / `保存到相册` / `发成笔记` / `晒到评论区` / `分享画册` / `双联对比` 全数收归底部拇指区；打开含 2 套以上的衣箱时默认自动预勾最新 2 套以便一键对比。
- **宋词色笺双向联动**：取消「全部」页签，顶部词人标签按 `poems.js` 分组点击即平滑锚点直达下方对应第一首词作，手动滚动词表时顶部词人高亮与位置实时同步。

## 规范与契约核验

- **在线文档核验**：2026-11-25 核对 `https://miniapp-sandbox.xiaohongshu.com/minitool/doc`（最后更新 `2026-11-25`，ETag `"554476357"`）。
- **已接入公开接口**：`getWindowInfo`（9.49+）与 `onWindowResize`、`setStorage` / `getStorage`（9.46+，严格不回退至 `localStorage`）、`vibrateShort`（9.50+ 轻触感）、`writeTempFile`（含模拟器 `/_xhsfile_/` 沙箱句柄识别）、`saveImageToPhotosAlbum`、`postNote`、`interactionOpenApi`（9.49+，接入 `readSnapshot()`）、`share`（9.53+）。
- **不调用**：关注弹窗（2026-11-30 下线）、定位、陀螺仪、内测 AI、云存储、成绩榜、赞赏。无 Worker、WASM、离屏画布或游戏引擎。`mini_tool.json` 为 `{"is_high_consumption_scene":false}`。
- **减少动态**：`prefers-reduced-motion: reduce` 与 `.reduce-motion` 下关闭动画、过渡与 Canvas 晕染插值。
