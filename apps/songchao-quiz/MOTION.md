# 测测你是宋朝哪种女子 · 运动系统（v1.1）

原则：运动只解释「刚刚发生了什么」。只动画 `transform` 与 `opacity`。时间与曲线全部走 CSS 变量。不把动画写在 `.view` 上，因为短屏适配会用它做等比缩放。

## 令牌

```css
--t-instant: 80ms;   /* 按下反馈 */
--t-fast:    160ms;  /* 选中回弹、题面离场、toast 进出 */
--t-base:    280ms;  /* 入场单件、切页 */
--t-slow:    420ms;  /* 结果卡、面板升降、印章 */
--t-hold:    260ms;  /* 选项选中后稍作停留 */
--t-calc:    800ms;  /* 「正在为你看气性」这一拍 */
--t-toast:   1800ms; /* 提示停留 */

--ease-out:    cubic-bezier(0.16, 1, 0.3, 1);
--ease-ink:    cubic-bezier(0.22, 1, 0.36, 1);
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);
```

错开间隔：`28ms`，同一序列最多计算前 12 项。

## 场景

- 首页入场：插画 → 引题 → 标题 → 线 → 说明 → 按钮，依次上移淡入。
- 开始测验：首页整框上收淡出，题面与进度入场。
- 题面进出：离场上移淡出，新题与选项错开入场。
- 选项点按：按下 `scale(0.98)`，选中后短暂回弹；颜色切换即时，不动画背景。
- 进度圆点：当前点缩放到 1.15，前进时弹一次。
- 结算拍：最后一题后进入「正在为你看气性」，横线 `scaleX` 画出，约 800ms 再揭晓结果。
- 结果揭晓：卡片轻微放大落定；纹样、类型名、说明、印章与按钮错开入场。
- 按钮：按下缩放；保存 / 发笔记 / 评论 / 关注成功时短暂放大并出 toast。
- 预览面板：遮罩只改透明度，面板自底部升起；关闭等过渡结束再隐藏。

## 减少动态

`prefers-reduced-motion: reduce` 或 `html.reduce-motion` 时，过渡与动画视为 `0.01ms`，不重播入场，直接到终态。仍保留状态变化与 toast 文案。
