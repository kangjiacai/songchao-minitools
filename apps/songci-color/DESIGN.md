# 宋朝配色 · 视觉方向（v3）

v2 的古风装裱（绢地、手卷、印章、织纹）和五套古风样张均已弃用。Jiacai 要求改成极简风，背景使用日常笔记的暖奶油色，不再使用古风元素。

## 对象、受众、任务

- 对象：离线小工具「宋朝配色」。抽一句宋词，展开一组依词意估算的颜色；也可按词人检索，或翻「宋色名录」。
- 受众：在小红书里对宋人审美、词、颜色感兴趣的人。
- 主任务：让颜色成为主角。界面只提供纸与字。

## 色彩

页面地色与「宋朝姑娘」笔记幻灯片完全一致：`#F7F2EA`。

取样来源：

- `/workspace/xhs/note25/slide01.png`、`slide02.png` 边框主色，RGB(247, 242, 234)
- `/workspace/xhs/note24/slide01.png`、`slide02.png` 同上
- 构建源码 `/workspace/xhs/note24/src/build.mjs`、`/workspace/xhs/note25/src/build.mjs`：`body{...background-color:#F7F2EA;...}`

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 纸 | `#F7F2EA` | 页面与导出色卡的地色，不加纹理 |
| 墨灰 | `#3A3732` | 标题、正文、主按钮、选中态。偏暖的深灰，不用冷蓝灰 |
| 淡墨 | `#8A847A` | 注释、出处、未选中底栏 |
| 细线 | `rgba(58, 55, 50, 0.12)` | 底栏顶线、搜索底线、次按钮描边 |

不再使用朱砂印章、粉青短线、生绢织纹。唯一的「强调」是墨色主按钮；饱和度全部留给抽到的四色。

## 字体

只用离线系统字体，不打包 webfont。

- 词句、首页标题：衬线 `"Songti SC", "STSong", "Noto Serif CJK SC", "Source Han Serif SC", "SimSun", serif`
- 界面（说明、按钮、底栏、色名、HEX、词人、名录）：无衬线 `"PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Source Han Sans SC", "Microsoft YaHei", system-ui, sans-serif`
- 层次靠字号、字重和留白，不靠装饰线。

## 布局

留白是结构。色块带 10px 圆角、彼此留缝，不做成通栏方切屏风。

```
首页（上题下钮，中间一条四色带）

  宋朝配色                         ← 衬线标题
  抽一句宋词，展开一组颜色。         ← 无衬线说明
  [  ][  ][  ][  ]                 ← 圆角色条，无标签
  意象取色，非文物实测
  [ 抽一句 ]                       ← 墨色小圆角按钮


色卡

  李清照《如梦令》
  知否，知否？应是绿肥红瘦。
  [  ]  [  ]  [  ]  [  ]           ← 四条圆角色柱，色名写在柱脚
  再抽一句 / 保存 / 分享
```

- 词人页、名录页：目录体例。词人是可点的字，选中时脚下一道短墨线。列表以空白分隔，不以卡片堆叠。名录每一条是一条圆角色带。
- 工具内不出现「宋朝姑娘」字样，不出现人物形象，不出现卷轴、窗棂、印章、开片、洒金、梅花或装裱边框。

## 运动

见 `MOTION.md`。令牌、曲线、错开、切页、抽词、点色、面板、toast 与减少动态回退保持不变，视觉上去掉织纹，圆角色块随同一套 `transform` / `opacity` 入场。
