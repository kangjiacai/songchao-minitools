# 宋朝配色 · 运动系统

原则：运动只解释「刚刚发生了什么」。只动画 `transform` 与 `opacity`。时间与曲线全部走 CSS 变量，JS 只切换 class、写入 delay、在需要时重启动画。

## 令牌

写在 `:root`，全站共用：

```css
--t-instant: 80ms;   /* 按下反馈 */
--t-fast:    160ms;  /* 选中态、小件显隐 */
--t-base:    280ms;  /* 切页、列表入场单件 */
--t-slow:    420ms;  /* 抽词色柱、面板升降 */
--t-toast:   1800ms; /* 提示停留（非过渡） */

--ease-out:    cubic-bezier(0.16, 1, 0.3, 1);
--ease-ink:    cubic-bezier(0.22, 1, 0.36, 1); /* 略慢落定，像墨晕开后停住 */
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);
```

距离也尽量固定，避免各写各的：

- 切页位移：`12px`（随前进 / 后退变号）
- 入场上移：`10px`（词句）、`16px`（色柱）
- 面板：自 `translateY(100%)` 升起
- 提示：自 `translateY(8px)` 升起
- 按下缩放：`scale(0.98)`，色块为 `scale(0.97)`

## 编排

- 错开间隔：`28ms`，同一序列最多计算前 12 项，之后都落在 `336ms`，避免长列表排队过久。
- 抽词色卡的顺序：词人词牌（0ms）→ 词句（70ms）→ 注释（120ms）→ 四条色柱（180ms 起，每柱 +70ms）→ 底部说明与按钮（460ms）。
- 一次只播一段入场。切走页面时立刻去掉 `is-enter` / `list-enter`，避免后台还在播。

## 场景

### 页面切换（底栏）

进入页：`opacity 0 + translateX(±12px)` → 复位，时长 `--t-base`，`--ease-out`。  
离开页：反向位移并淡出，结束后再摘 class。  
前进（首页→色卡→词人→宋色）从右侧进，返回从左侧进。  
底栏当前项：按钮下方短墨线 `scaleX(0→1)`，`--t-fast`。

### 抽词 / 再抽一句（色卡显现）

给画心加 `is-enter`（先移除再强制回流以重播）。词句略上移淡入，色柱随后错开升起，像设色依次上绢。已在色卡页再抽时，只重播这段，不再切页。

### 点色块

`:active` 时 `scale(0.97)`，`--t-instant`。随即打开色值面板；若平台有 `vibrateShort`，同时给一次轻振。

### 底栏切换

见「页面切换」。点到「色卡」且尚未抽词时，先抽一句再入场。

### 列表入场

进入「词人」「宋色」时，给列表加 `list-enter`。子项 `opacity 0 + translateY(8px)` 错开入场。搜索或筛选只换内容，不再重播，以免打字时闪动。

### 面板开合（色值、预览）

遮罩只变动 `opacity`（0→1），`--t-base`。  
面板 `translateY(100%) → 0`，`--t-slow`，`--ease-drawer`。  
关闭走反向；过渡结束后再隐藏，避免中途被 `hidden` 掐断。  
色值面板顶部是整块颜色，HEX 大号、可选择（容器禁用剪贴板）。

### 保存 / 分享反馈

成功或失败都用同一套 toast：`opacity + translateY(8px)`，`--t-fast` 进入，约 1800ms 后淡出。文案与按钮用语一致：「已保存到相册」「暂时无法分享」。

### 按钮

主按钮与次按钮 `:active` 为 `scale(0.98)`。没有循环呼吸、没有悬停才出现的关键操作。

## 减少动态

`prefers-reduced-motion: reduce` 时：

- 所有过渡与动画时长视为 `0.01ms`，缓动取消。
- 不重播入场 class，页面与面板直接到终态。
- 仍保留状态变化（开合、切页、toast 文案），只去掉位移与淡入。
- JS 用 `matchMedia('(prefers-reduced-motion: reduce)')` 同步判断，并监听变化。

## 性能

- 只动画 `transform` / `opacity`，不动画宽高、颜色、阴影或 `blur`。
- 不用常驻循环动画，不用整页 `filter`。
- 织纹是静态 CSS 重复渐变，不参与动画。
- 列表不超过现有词句与名录规模，搜索已防抖；入场 delay 有上限。
- 真机帧率未实测，交付时需标明。
