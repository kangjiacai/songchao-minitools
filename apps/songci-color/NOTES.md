# 宋朝配色备忘

## 版本
- v3（当前）：极简风。地色 `#F7F2EA`（与笔记幻灯片一致）。无古风装饰、无「宋朝姑娘」字样、无人物形象。
- v2：生绢古风，已弃用。


## 名称与形象
- 工具名统一为「宋朝配色」。
- 工具内不出现「宋朝姑娘」字样，不放人物形象。

## 数据
- 宋词 60 句，每句 4 色，共 240 个色值。
- 宋色名录 43 条，均附简短出处。色值为示意。
- 页面统一注明「意象取色，非文物实测」。
- 不收作者归属有争议的词句。南唐词亦不收。

## 收入时加了说明的句子（作者本身清楚）
- 晏几道「落花人独立，微雨燕双飞」：原出五代翁宏《春残》，晏几道整句借用。
- 秦观「山抹微云，天粘衰草」：「天粘」又作「天连」；叶梦得《避暑录话》记作「天粘」。

## 因作者争议未收入 / 已从 v1 撤下
- 欧阳修「庭院深深深几许」（《蝶恋花》）：亦见冯延巳《阳春集》，归属有争议。已撤下，改收欧阳修《玉楼春》「人生自是有情痴，此恨不关风与月。」
- 「月上柳梢头，人约黄昏后」（《生查子·元夕》）：欧阳修 / 朱淑真两说长期并存，不收。
- 岳飞《满江红·写怀》「怒发冲冠」：著作权有争议，不收。

## 容器限制
剪贴板 API 不可用。点色块会弹出大号 HEX，文本可选中；并引导保存色卡。
