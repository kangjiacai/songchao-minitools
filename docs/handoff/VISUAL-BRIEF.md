# 宋式衣橱 · 短视觉 brief

给 CloudAgent 的实现方向，不是完整设计报告。不要现在开始做衣橱。不要改已上线的「宋朝配色」「测测你是宋朝哪种女子」角色或画风。

## 对象

离线小工具「宋式衣橱」：用户自选场景（出门、赏花、冬日等），搭衫、褙子、裙和头饰，自选颜色，保存一整套能晒的搭配图。这是「自己搭」，不是再做一套测验或抽色。

## 色彩

- 纸地必须用奶油色 `#F7F2EA`，与「宋朝姑娘」笔记和「宋朝配色」地色一致。
- 墨色用偏暖深灰，不用冷蓝灰。饱和度留给衣料、花色和首饰，不要再叠一层装饰性强调色。
- 不要做成通用的「奶油底 + 衬线标题 + 陶土强调」模板；地色是既定约束，个性放在衣饰剪裁、层叠和人物绘制上。

## 人物与服装

- 需要精细的宋式人物和可层叠服装，为换装绘制：分件（衫、褙子、裙、头饰等）要对齐同一身材与透视，叠穿合理，不是整身换一张图。
- 不沿用旧笔记里的固定角色限制，也不复用「测测你是宋朝哪种女子」的结果形象；衣橱人物是新画的、为换装服务的一套。
- 「宋朝配色」工具内本来就没有人物，保持原样，不要往旧工具里加人或改角色。
- 第一版只要少量能互相搭配的衣饰，成品图要漂亮，不做庞大换装游戏，不要求用户登录或上传真人照片。

## 界面气质

像一本可以动手的衣橱册页，而不是仪表盘或卡片墙。留白是结构；按钮文案直说动作（保存搭配、发成笔记）。运动只解释刚发生的换装或开合，尊重减少动态。
