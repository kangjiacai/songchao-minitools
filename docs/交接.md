## 启动和打包

在仓库根目录：

```bash
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/apps/song-wardrobe/pkg/index.html 。不要只双击 `index.html`，浏览器会拦住画布读像素。

打包：

```bash
sh tools/pack.sh
```

zip 出现在 `dist/`，不进 git。衣橱包根目录直接有 `index.html`。
