# 开发与打包

## 目录

```
apps/songci-color/pkg/       宋朝配色运行包
apps/songchao-quiz/pkg/      测验运行包
apps/song-wardrobe/pkg/      宋式衣橱运行包
docs/handoff/                交接盘点，只读
docs/contract/               2026-11-24 在线契约快照与和 2026-09-23 基线的对照
tools/minitool-zip-builder/  交接里的打包规范与审计脚本
tools/pack.sh                打三个 zip
tools/browser-check.mjs      衣橱与旧款首页的本地浏览器检查
```

`pkg/` 里不要放说明文档。说明放在 `pkg` 外面，避免被打进上传 zip。

## 最低支持

| 项 | 要求 |
| --- | --- |
| 脚本 | 直接交付的 JS 停在 ES2017。不用可选链、空值合并、对象展开、`import` / `export`、顶层 await |
| 样式 | Chrome 61 能完成布局。Flex 间距用 margin，不把 `gap` 当唯一方案。安全区先写固定内边距，再用 `var` / `env` 增强 |
| 资源 | 全部在 zip 内。无外部字体、CDN、网络图片 |
| 脚本形态 | 经典脚本。无内联脚本、无行内事件、无 `eval` / `new Function` |
| 高消耗 | 衣橱不用 Worker、WASM、离屏画布、游戏引擎 |

## 打包

```bash
sh tools/pack.sh
```

脚本会对每个 `pkg` 目录和打出来的 zip 跑 `tools/minitool-zip-builder/scripts/audit_artifact.py`。zip 根上必须能直接看到 `index.html`。

衣橱的 `mini_tool.json` 用同一套 `write_manifest.mjs` 写成布尔值 `false`。旧两款的这个文件保持交接时的字节，不重新生成。

## 契约

本次又拉取了 https://miniapp-sandbox.xiaohongshu.com/minitool/doc 。响应 ETag 为 `487330165`，Last-Modified 为 2026-11-24 02:54:11 GMT，与 `docs/handoff` 里的快照相同。实现以这份在线文档里写明对外开放、并有用法的接口为准。

衣橱实际调用：

- `getWindowInfo`（9.49+）做顶部按钮和安全区避让；没有返回时用 CSS 回退
- `setStorage` / `getStorage`（9.46+）记住最后一套；没有则用 `localStorage`
- `writeTempFile`、`saveImageToPhotosAlbum`、`postNote`
- `interactionOpenApi`（9.49+）：图片只用临时文件句柄
- `share`（9.53+，仅全屏，每天 10 次）：分享这一张竖图

不调用：`followAuthor`、`getFollowStatus`、定位、陀螺仪、`window.xhs.AI`、云存储、成绩榜、赞赏。

评论区重新打开时，在线文档让开发者自己恢复 `miniToolSnapshotInfo`，但没有写明字段在启动参数的哪一层。衣橱只在常见嵌套里找；找不到就用上次记住的一套。

## 浏览器检查

先在仓库根目录启动静态服务，再：

```bash
python3 -m http.server 8765
node tools/browser-check.mjs
```

这个检查只覆盖桌面 Chrome。它不能代替创服模拟器、Android 真机和 iOS 真机。
